### Vertical Speed

Telemetry Item

* int16_t Vertical Speed - cm / s (e.g. 1.5m/s sent as 150)

This is the standalone vertical speed telemetry item for use with GPS-based variometers. If the system has a barometer, then the [[CRSF_FRAMETYPE_BARO_ALTITUDE]] type should be used instead to include both the altitude and vertical speed.
